Description: A pink-themed Q&A forum for developers built with the 3-Tier architecture. Users can register, log in, browse categories, ask questions, and post answers.
How to Use: 1. Register an account or log in with an existing one
2. Pick a category from the sidebar on the dashboard
3. Click any question to read it and post an answer
4. Click + Ask a Question to post your own question
5. Click Logout when you're done
Technology Used: React — frontend single page application
Node.js & Express — backend REST API
MySQL — database for users, questions, and answers
JWT & bcrypt — authentication and password security
React Router — client-side navigation
3 Things to Improve

Search functionality — allow users to search questions across all categories instead of browsing one category at a time
